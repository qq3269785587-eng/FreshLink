# 生鲜课设课堂演示方案

正式题目：面向连锁餐饮的生鲜食材仓储与配送管理系统。

版本 v2.1，2026-11-18。用户明确以课堂演示为主，仅剩两天；教师要求在原 WMS 基础上改造。本版替代原 v1.2 的 P2～P7 后续计划，保留 P0、P1 已独立验收通过的事实。D1、D2、D3、D4 均为待实施，不因修改文档而完成。

## 当前范围

一个配送中心、多个餐饮门店、固定包装整数计数。先补齐 D1 基础模块，再复用原 WMS 和 P1 基础资料完成批次入库、上架、库存效期、人工选批出库、配送登记和送达状态。总部或仓管统一操作，门店账号保留 P1 本店只读权限。

确认出库是唯一扣库存动作，同时生成唯一待配送单。配送中和已送达只改变配送状态，不再次扣库。送达为仓管登记，不宣称门店签收。

移出本次必做：AI、门店申领审批、自动 FEFO、波次与独立拣货、复杂签收异常及退货、门店库存、IoT、地图路线、复杂看板和全新机器干净部署。移出项不能写成已实现或已验收。
